Tips before you apply

  1. One OHEP application covers both EUSP and MEAP.
  2. Already getting a state benefit with a 200% FPL limit? Water4All has a shorter application for you.
  3. Renters can get Water4All even if the water bill is in the landlord's name.
  4. Water4All lasts one year. Set a reminder to renew.
  5. Behind on BGE? Ask about arrearage retirement (past-due help) when you apply.
